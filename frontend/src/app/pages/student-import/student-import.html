Schüler importieren

Klassenliste aus WebUntis als CSV exportieren und hier hochladen – oder die Namen einfach aus einer Tabelle einfügen. Fehlende Klassen werden angelegt.

Zur Verwaltung
Wo finde ich die Liste in WebUntis?

In WebUntis unter Stammdaten → Schüler die Klasse auswählen und über das Export-Symbol als CSV herunterladen. Erkannt werden die Spalten Langname beziehungsweise Nachname, Vorname und Klasse – in beliebiger Reihenfolge. Fehlt die Klassenspalte, wählen Sie unten eine Klasse für alle Zeilen.

Hat Ihr Zugang keinen Export, markieren Sie die Namen in der Klassenliste, kopieren sie und fügen sie unten ein.
